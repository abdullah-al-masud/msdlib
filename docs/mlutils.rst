mlutils
===============

This module provides machine learning training and evaluation utilities.

Sklearn-compatible helpers such as ``train_with_data``, ``evaluate_with_data``, ``store_models``, and ``load_models`` work without PyTorch.

When PyTorch is installed (``TORCH_AVAILABLE`` is ``True``), deep learning support is also available through ``torchModel``, ``define_layers``, and ``DataSet``.
